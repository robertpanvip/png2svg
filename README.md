# png2svg

面向 **icon** 的 PNG → SVG 转换工具（Rust 实现）。

与常见的「先二值化、再描边」思路不同，本工具**不单独做黑白轮廓**：
轮廓来自**颜色 / alpha 差异自然划分出的区域边界**——相邻像素颜色几乎一致就并入同一区域，
区域之间的边界就是轮廓。每个区域再被识别为 **纯色 / 渐变 / 阴影** 三类，并据此生成 SVG。

## 算法概览

1. **前景掩码**
   - 有透明通道：alpha ≥ 阈值即前景（阈值调低可纳入半透明阴影）。
   - 无透明通道：以四边平均色为背景，颜色距离 > 阈值即前景（`--invert` 可翻转）。

2. **区域分割（替代「黑白轮廓」）** — `src/segment.rs`
   - 对每个未访问像素做 **4 邻域漫水填充**，扩展条件是「与相邻像素的综合距离 ≤ 容差」：
     `距离 = √(RGB² + (α权重 · α差)²)`。
   - 即「遍历每个像素每个方向」：相邻色一致 → 合并为**纯色/渐变区域**；半透明像素因 α 差巨大 → 自动切出**阴影区域**。
   - 区域边界用 Moore 邻域跟踪 + 孔洞检测提取（`src/contour.rs`），按 **圆 → 旋转椭圆 → 贝塞尔/多边形** 优先级识别：
     - **圆 / 旋转椭圆** → 真弧（`A` 命令，旋转椭圆带 `x-axis-rotation`）。椭圆用 PCA 估计主轴方向、旋转到主轴坐标系后做轴对齐拟合；因此**旋转椭圆也被识别为单个椭圆弧**，而不是碎成数十条贝塞尔；
     - **其余曲线型轮廓** → 用 **「切线 + 曲率分析」重建**：沿轮廓算每点切线与有符号曲率（滑动平均抑制像素台阶噪声），在曲率极值 / 拐点 / 折角处放置结点（带最小角间距、上限 24 个），结点作为控制点做闭合 Catmull-Rom，得到与曲率特征数量相当的少数干净三次贝塞尔（极曲折时退化为较粗 RDP + Catmull-Rom）；
     - **直线 / 直角轮廓** → 保留多边形；`evenodd` 保留内孔。

3. **三类识别** — `src/gradient.rs` + `src/main.rs`
   - 对每个区域**同做一次最小二乘拟合**，并行估算三种渐变模型（每通道 R/G/B 独立）：
     - **线性（平面）** `c = a + b·x + c·y`（2×2 求解）；
     - **径向** `c = a' + k·r`，`r` 为到质心的距离（2×2 `[1, r]` 求解）；
     - **网格（双线性）** `c = a + b·x + c·y + d·x·y`（3×3 高斯消元求解）。
   - 用各自的 **R²** 决定最终类型，优先级：
     - **阴影**：区域平均 alpha 低于 `--shadow-alpha` → 渲染时降低不透明度，画在**最底层**；
     - **径向渐变**：`radial_r2 ≥ 0.85` 且 `radial_r2 ≥ linear_r2 − 0.02`；
     - **网格渐变**：`bilinear_r2 ≥ 0.95` 且 `bilinear_r2 − linear_r2 ≥ 0.02`；
     - **线性渐变**：其余 R² 高且整片颜色变化量 > `--solid-eps` 的区域；
     - **纯色**：其余兜底，取区域均值色。
   - 说明：判据是「R² + 整片颜色变化量」，而非「每像素梯度幅值」——后者会把
     每像素只变一点点、但整片跨度很大的**真实平缓渐变**误判成纯色。
     径向只在不比线性差太多时才采用（避免把斜向线性错认成径向）；网格只在明显优于线性时采用。

4. **SVG 渲染** — `src/svg.rs`
   - **线性渐变** → `<linearGradient gradientUnits="userSpaceOnUse" x1 y1 x2 y2>` + `fill="url(#g)"`；
   - **径向渐变** → `<radialGradient gradientUnits="userSpaceOnUse" cx cy r fx fy>`（2 个色标：圆心色 / 边缘色）；
   - **网格渐变** → `<clipPath>` 裁出区域轮廓 + 内部一张 `cols×rows` 的 `<rect>` 网格，每个格子填双线性插值得到的颜色（网格密度随区域尺寸自适应，`dim/8` 并夹在 `4–64`）；
   - 纯色区域 → `fill="rgb(...)"`；
   - 阴影区域 → 同上但带 `fill-opacity`，且绘制顺序排在最前（底层）。

## 构建

```bash
cd png2svg
cargo build --release
# 二进制位于 target/release/png2svg(.exe)
```

> 国内网络建议在 `~/.cargo/config.toml` 配置 rsproxy 等镜像加速依赖下载。

## 用法

```bash
# 转换单个图标
png2svg input.png -o output.svg

# 生成测试图标（含渐变环 + 纯色块 + 半透明阴影）
png2svg gen-test test_icon.png

# 转换测试图标，查看三类识别效果
png2svg test_icon.png -o out.svg
```

### 可调参数

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `--tolerance N` | 28 | 颜色 + alpha 分割容差；越大区域越「粗」，越小越细碎 |
| `--alpha N` | 8 | 前景 alpha 阈值（0–255）；调低可纳入更淡的阴影 |
| `--bg-thresh N` | 40 | 无 alpha 时的背景距离阈值 |
| `--shadow-alpha N` | 230 | 区域平均 alpha 低于此值判为阴影 |
| `--invert` | 关 | 无 alpha 时翻转前景 / 背景 |
| `--solid-eps N` | 8 | 判定为渐变的最小整片颜色变化量 |
| `--r2 N` | 0.6 | 判定为渐变的最小 R² |
| `--simplify N` | 0.5 | 轮廓简化精度（越小点越密） |
| `--no-smooth` | 关 | 关闭曲线平滑：非椭圆曲线回退为纯多边形（配合小 `--simplify` 可得极密多边形）。圆/旋转椭圆检测在平滑之前，始终渲染为真弧 |
| `--circ-tol N` | 0.06 | 圆拟合容许误差/半径（越小越严格） |
| `--ell-tol N` | 0.06 | 椭圆拟合容许误差（越小越严格） |

## 项目结构

```
src/raster.rs    图像加载（RGBA）、前景掩码辅助
src/segment.rs   按颜色 + alpha 漫水填充分割区域
src/contour.rs   Moore 边界跟踪 + 孔洞检测 + RDP 简化
src/gradient.rs  三种渐变模型（线性 / 径向 / 网格）最小二乘拟合与纯色 / 渐变 / 阴影判定
src/svg.rs       SVG 文档构建（渐变/纯色/阴影三类）
src/main.rs      CLI 串联三步流程，含 gen-test
```

## 示例输出

`gen-test` 生成的图标含 4 个区域，转换后：
- 渐变环 → `<linearGradient>`（含内孔，`evenodd` 保留）；
- 绿块 / 红块 → 纯色填充；
- 半透明椭圆 → `fill-opacity` 降低不透明度，绘制在底层。

渐变三类型演示图（由 `gen_grads.py` 生成 PNG，再用 `png2svg x.png -o x.svg` 转换）：
- `linear.png` → `linear.svg`：横向红→蓝线性渐变 + 绿方块 → 输出 `<linearGradient>`；
- `radial.png` → `radial.svg`：白→深蓝的径向渐变圆盘 → 输出 `<radialGradient>`（圆心白、边缘深蓝）；
- `mesh.png` → `mesh.svg`：四角双线性配色（红/黄/蓝/绿）方块 → 输出 `<clipPath>` + 插值 `<rect>` 网格（网格渐变）。

> 注：渐变测试图 **必须带透明背景**（真实 icon 才有 alpha）。全不透明 PNG 会触发
> 「无 alpha → 用四边平均色当背景」分支，把中间近似背景色的部分误判为背景，导致渐变出现缺口。

附带的轮廓演示图（均可用 `png2svg x.png -o x.svg` 直接生成）：
- `curve.png` → `curve.svg`：旋转 30° 的椭圆，被识别为**单个旋转椭圆弧**（`A` + `x-axis-rotation`），而非碎成多条贝塞尔；
- `blob.png` → `blob.svg`：非椭圆的平滑三叶曲线，用「切线 + 曲率分析」重建为**少数几条三次贝塞尔**（`C`）；
- `star.png` → `star.svg`：星形，尖角保留、不磨圆（多边形）。
